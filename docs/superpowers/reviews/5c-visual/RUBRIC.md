# Phase 5C Visual Judging Rubric

Three independent vision judges score each dimension 1–5. **Median ≥ 4 required per
dimension.** Judges see: screenshots at 390 / 768 / 1440 for home, program page
(dossier + flow: /program/0601101E/), program page (plain: sampled), feed, district
index, citation-panel-open (home receipt moment clicked), plus short recordings of
panel-open and follow-the-dollar where available.

Score each dimension with 2-3 sentences of justification citing specific screenshots.
A 5 = best-in-class for a civic-data product; 4 = professional, minor nits; 3 =
competent but generic or with visible rough edges; ≤2 = fails the bar.

## Inherited dimensions (5B baseline — regression watch)

| D1 | Visual hierarchy & typography — scan order matches importance; consistent scale |
| D2 | Data presentation — tables/figures legible, aligned, honest units |
| D3 | Responsive integrity — 390/768/1440 all coherent; no overflow/clipping/cramping |
| D4 | Citation affordance clarity — cited vs uncited states distinguishable; chips readable |

## Phase 5C dimensions

**V1 — Receipt-moment credibility (Goal 1).** "Would a skeptical journalist believe
this site's numbers within 30 seconds — and could they say why?" Judge the home page
top fold: does the featured cited figure invite the click; does the panel-open state
(screenshot) deliver visible proof (PDF page with highlight)?

**V2 — Honest completeness (Goal 3).** "Does any chart or table imply completeness it
doesn't have?" Coverage notes present and legible at point of use; empty states
explain absence; the answer strip's honest-absence line reads as information, not
error. Any implied-completeness finding caps the score at 2.

**V3 — Journey legibility (Goal 4).** Could a non-expert complete each core job
(verify a number / district view / track winners / download / read a dossier) from
what is VISIBLE — persona row clarity, nav completeness, no insider jargon in entry
points?

**V4 — Tells-not-shows (Goal 5).** "Does each page tell me something, or just show me
something?" Program page top fold must answer what/changed/who; home leads with a
finding. Influence surfaces: ZERO causal language (any "because of lobbying"-type
phrasing caps at 1).

**V5 — Motion design & modernity (Goal 6).** Consistency (one easing family, token
durations), restraint (no bounce, no gratuitous movement), purpose (motion stages
content — reveals, panel slide, story animations decorate real data). Judge from
recordings + any visible mid-animation states; also judge that static frames don't
show half-revealed content stuck mid-transition.
